# 📚 BCS Verse v3.0 — মাল্টি-পেজ স্টাডি নেটওয়ার্ক

৫১তম বিসিএস প্রস্তুতির জন্য সম্পূর্ণ কার্যকর, লোকাল-ফার্স্ট **সোশ্যাল স্টাডি নেটওয়ার্ক**।
এখন **৪টি আলাদা পেজ** — হোম, লাইভ স্টাডি, এআই মেন্টর, প্রোফাইল — এবং সেগুলোর মধ্যে
হেডার নেভিগেশন সম্পূর্ণ কাজ করে।

## 🗂️ ফাইল স্ট্রাকচার

```

bcs-verse/
├── index.html        # হোম ফিড (টাইমলাইন + কম্পোজার)
├── live.html         # লাইভ স্টাডি রুম ও ফোকাস ককপিট
├── ai.html           # Gemini এআই মেন্টর — ফুল চ্যাট ইন্টারফেস
├── profile.html      # প্রোফাইল, ব্যাজ, সেটিংস
├── css/
│   └── style.css     # সম্পূর্ণ ডিজাইন সিস্টেম
└── js/
├── config.js     # বিষয়, প্রিসেট, সিড ডেটা
├── store.js      # localStorage স্টেট
├── ai.js         # Gemini Interactions API
├── ui.js         # টোস্ট, মডাল, ফরম্যাটিং
└── app.js        # পেজ কন্ট্রোলার

```

## 🚀 চালানোর নিয়ম

শুধু `index.html` ব্রাউজারে ডাবল-ক্লিক করুন।
অথবা লোকাল সার্ভার:

```bash
npx serve
```

> হেডার নেভিগেশন কাজ করতে ফাইলগুলো একই ফোল্ডারে রাখতে হবে।

## 🔑 Gemini API Key

1. [Google AI Studio](https://aistudio.google.com/apikey) থেকে বিনামূল্যে key নিন
2. **এআই মেন্টর** পেজ → ডান পাশের "API স্ট্যাটাস" কার্ডে key পেস্ট করুন
3. **🔍 যাচাই** চাপুন

Key শুধু আপনার ব্রাউজারে (localStorage) সংরক্ষিত হয়।

## 📄 পেজগুলো

### `index.html` — হোম ফিড

- লাইভ অ্যাক্টিভিটি স্ট্রিপ
- ফোকাস টাইমার (SVG রিং)
- পোস্ট কম্পোজার (Ctrl+Enter = পাবলিশ)
- ফিল্টার ট্যাব: সব / লাইভ / আমার / সেভড

### `live.html` — লাইভ স্টাডি

- বড় ফোকাস ককপিট + সেশন টাইপ সেগমেন্ট
- রুম গ্রিড (ফিল্টার + সার্চ)
- স্টাডি পার্টনার লিস্ট
- আজকের ফোকাস লিডারবোর্ড

### `ai.html` — এআই মেন্টর

- বাম পাশে চ্যাট হিস্টোরি
- কেন্দ্রে ফুল-হাইট চ্যাট
- ৬টি প্রিসেট + বিষয়ভিত্তিক চিপস
- মডেল সিলেক্টর (gemini-3.6-flash ডিফল্ট)
- API key প্যানেল

### `profile.html` — প্রোফাইল

- কভার + অ্যাভাটার হিরো
- ৫টি স্ট্যাট
- ট্যাব: অ্যাক্টিভিটি / অ্যাচিভমেন্ট / বিষয় অগ্রগতি / সেটিংস
- ৮টি ব্যাজ, স্ট্রিক হিটম্যাপ, সাপ্তাহিক লক্ষ্য

## ⌨️ কীবোর্ড শর্টকাট

| কী ↕▾ | কাজ ↕▾ |
|---|---|
| −`G` | হোম |
| −`L` | লাইভ |
| −`A` | এআই |
| −`P` | প্রোফাইল |
| −`Ctrl/Cmd + Enter` | পোস্ট পাবলিশ |
| −`Esc` | মডাল বন্ধ |
⚙

## 🔧 কাস্টমাইজ

- **বিষয়** → `js/config.js` → `BCS.SUBJECTS`
- **প্রিসেট প্রম্পট** → `BCS.PRESETS`
- **সিড ডেটা** → `BCS.SEED_POSTS`, `SEED_ROOMS`, `SEED_LIVE`
- **থিম কালার** → `css/style.css` → `:root`
